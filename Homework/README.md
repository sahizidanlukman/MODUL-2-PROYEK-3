# Interactive Profile Card (Modul 2 Homework)

Proyek ini dibangun menggunakan Vanilla JavaScript dan mengimplementasikan Asynchronous Fetch, DOM Manipulation, DOM Events, Form Validation, serta State Management.

## Cara Menjalankan

Proyek ini memuat file JSON lokal data/profile.json menggunakan fetch. Browser memblokir akses HTTP fetch ke file lokal melalui protokol file:// dengan alasan keamanan (CORS policy).

Untuk menjalankannya:

 Menggunakan VS Code :
   - Install ekstensi Live Server.
   - Buka folder proyek ini di VS Code.
   - Klik kanan pada index.html dan pilih Open with Live Server.


## Fitur yang Dicakup

- Fetch API dengan Async/Await
- State Management (Loading, Error, Empty, Success)
- DOM Manipulation (menggunakan createElement dan textContent)
- Toggle Class dan Aksesibilitas (aria-expanded)
- Form Validation (mencegah string kosong terkirim)
- Delete functionality (menghapus item pada list keterampilan)S
